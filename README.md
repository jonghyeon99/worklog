# WorkLog

FlaskとPostgreSQLを使用した勤怠・有給休暇管理Webアプリケーションです。

日々の出退勤記録や勤務時間、有給休暇の付与・使用履歴を管理できます。また、カレンダー上で出勤日や有給休暇の取得状況を確認できます。

## 使用技術

- **バックエンド**：Python / Flask
- **データベース**：PostgreSQL
- **フロントエンド**：HTML / CSS / JavaScript
- **インフラ**：AWS EC2（Ubuntu）
- **Webサーバー**：Nginx
- **アプリケーションサーバー**：Gunicorn
- **サービス管理**：systemd

## 主な機能

### ユーザー管理

- ユーザー新規登録
- ログイン・ログアウト
- ユーザーごとのデータ管理

### 勤怠管理

- 勤怠記録の登録・一覧表示・編集・削除
- 出勤・退勤時刻、休憩時間、メモの管理
- 月別の勤怠記録検索
- 月間勤務日数・実働時間の集計

### 有給休暇管理

- 有給休暇の付与履歴管理
- 有給休暇の使用履歴管理
- 全休・午前半休・午後半休の登録
- 有給休暇の残日数管理
- 付与・使用履歴の編集・削除

### 勤怠カレンダー

- 月別の勤怠・有給休暇記録の表示
- 出勤・全休・午前半休・午後半休の色分け表示
- 前月・翌月への切り替え
- カレンダーからの勤怠登録・編集

## ローカル環境のセットアップ

1. Python仮想環境を作成し、有効化します。
2. `pip install -r requirements.txt` を実行します。
3. `.env.example` を参考に `.env` を作成します。
4. PostgreSQLにデータベースを作成し、`schema.sql` を適用します。
5. `python app.py` でアプリケーションを起動します。

※ PostgreSQLの接続設定は、実行環境に合わせて設定してください。

## データベース

主なテーブル：

- `app_user`：ユーザー情報
- `user_settings`：ユーザーごとの勤務時間設定
- `attendance`：勤怠記録
- `paid_leave_grant`：有給休暇の付与履歴
- `paid_leave_usage`：有給休暇の使用履歴

## デプロイ構成

AWS EC2（Ubuntu）上にアプリケーションを配置し、NginxとGunicornを使用して公開しています。

`Client → Nginx → Gunicorn → Flask → PostgreSQL`

アプリケーションのプロセスはsystemdで管理しています。
